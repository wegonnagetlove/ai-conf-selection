# Отбор докладов: «Технологии ИИ в науке и образовании» 2026

Страница для экспертного отбора докладов IV Международной молодежной научной конференции «Технологии ИИ в науке и образовании» (conf.msu.ru, мероприятие 10771).

Рабочая страница для экспертов: https://claude.ai/artifact/HjvBcbKeU47ShmMM7fSu4L (доступ только у приглашённых).

## Состав

- `site/index.html`: страница: папки по секциям, карточки докладов, отметки «Выбрать / Под вопросом / Не подходит», комментарии, сводка с копированием таблицы.
- `site/data/sections.json`: доклады, сгруппированные по 13 секциям (без телефонов, адресов почты и дат рождения).
- `scripts/parse.py`: разбор выгрузки заявок conf.msu.ru (XML Spreadsheet `.xls`).
- `scripts/build.py`: сборка `sections.json`: соавторы присоединяются к основному докладу по номеру родительской заявки, второй доклад автора уходит в свою секцию, слушатели форума исключаются.

Отметки экспертов хранятся в хранилище страницы Claude и привязаны к ключу `<номер заявки>-<1|2>`, поэтому при обновлении списка заявок они сохраняются.

## Обновление списка заявок

```bash
python3 scripts/parse.py путь/к/request_list_event_10771_….xls
python3 scripts/build.py
rm rows.json
```

После этого обновлённый `site/data/sections.json` публикуется на страницу. Исходная выгрузка в репозиторий не добавляется (`.gitignore`), так как содержит контактные данные участников.

## Доступ экспертов

Владелец страницы открывает её на claude.ai, нажимает «Поделиться» и выдаёт экспертам уровень «Участник» (Contributor). С уровнем «Наблюдатель» отметки ставить нельзя.
